# Recipes

A simple, playful recipe app you can install on your phone.

- 📋 **Ingredient checklist**: tick items off while shopping, works offline
- 👩‍🍳 **Step-by-step cooking**: numbered steps, mark them done as you go
- 🔐 **Google login**
- 📱 **Installable PWA**: no app store needed

**Stack:** Angular · NgRx Signal Store · Node.js · TypeScript · Fastify · SQLite
